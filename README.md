# TCP Bench

在你的 VPS 上跑一下访问全球主流网站的真实延迟，看看这台机器上网快不快。

```bash
curl -sL https://tcpbench.com/run.sh | bash
```

跑完会返回一个报告链接，打开就能看到每个站点的延迟表格和趋势图，可以直接分享给别人看。

## 这是干什么用的

买 VPS 最怕的就是"看起来很美，用起来很卡"。标着同样机房，有的线路刷 YouTube 秒开，有的连网页都打不开。

TCP Bench 做的事情很简单：对你的 VPS 到 **Google、YouTube、GitHub、Netflix、Discord、ChatGPT** 等约 60 个全球主流站点实际发起 TCP 连接，记录每一次的握手耗时，最后给出一份真实可参考的访问速度报告。

不管这些站点套没套 CDN——你实际用起来就是连到这些域名，测的就是你真实的上网体验。

## 用起来什么样

1. 在你的 VPS 上执行上面那条命令
2. 脚本会依次测试约 60 个站点，每个采样 60 次，实时打印进度
3. 测完自动上传结果，返回一个报告链接
4. 打开链接能看到：整体平均延迟、最快/最慢站点、每个站点的详细延迟和趋势折线图
5. 右上角「导出图片」可以把整份报告存成 PNG，方便发论坛或群里

## 为什么不用 Speedtest

Speedtest 测的是带宽大小，但带宽大不等于网站访问快。TCP Bench 测的是**你实际访问这些网站时的握手延迟**，更能反映日常上网体验。

## 隐私

- 脚本在你自己 VPS 上本地执行，**不需要任何账号、密码或密钥**
- 上传结果前会自动对 IP 后两段打码（如 `1.2.*.*`）
- 只包含各站点的延迟数据和打码后的 IP，不涉及其他信息
- 源码完全公开，不放心可以先看一遍再跑

## 环境要求

- Linux，bash 3.2+
- 出站 443 端口通畅
